# clm-terraform

BigFix CLM blueprint'indeki **Execute terraform file** nesnesiyle çalıştırılan Terraform klasörleri. Her klasör bir katalog olur.

| Klasör | Ne kurar |
|---|---|
| `gcp-network-storage` | VPC, subnet, firewall kuralı, Cloud Storage bucket |

- Repoya şifre, anahtar ya da kimlik dosyası konmaz.
- Kaynak adlarına rastgele bir ek gelir, aynı katalog tekrar tekrar istenebilir.
